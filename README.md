Welcome to **javascript-fundamentals** – your essential guide to learning and practicing the core concepts of JavaScript.

---

## 🔍 What You’ll Learn

![Concept Map](https://via.placeholder.com/900x200?text=Variables+%7C+Loops+%7C+Functions+%7C+DOM+%7C+Events+%7C+ES6)

- ✅ Variables & Data Types (`var`, `let`, `const`)
- ✅ Operators & Expressions
- ✅ Conditional Statements (`if`, `else`, `switch`)
- ✅ Loops (`for`, `while`, `do...while`)
- ✅ Functions (declaration, expression, arrow functions)
- ✅ Arrays & Objects
- ✅ DOM Manipulation
- ✅ Events & Event Listeners
- ✅ ES6+ Features (Destructuring, Spread, Classes)
- ✅ JSON & Fetch API Basics
